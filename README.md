# LeetCode Clone with AI Hints

An AI-powered coding practice platform inspired by LeetCode.

## Project Objectives

- Practice coding problems in a web-based editor.
- Execute code in a Docker-based sandbox.
- Provide progressive AI hints without immediately revealing full solutions.
- Analyze time and space complexity.
- Generate test cases and identify edge cases.
- Track submissions and user progress.

## Planned Technologies

- **Frontend:** React
- **Backend:** Node.js
- **Code Execution:** Docker
- **Database:** Amazon DynamoDB
- **Queue:** Amazon SQS
- **AI Features:** Amazon Bedrock
- **Cloud Infrastructure:** AWS
- **CI/CD:** GitHub Actions

## Project Status

Currently in the initial setup and development phase.
